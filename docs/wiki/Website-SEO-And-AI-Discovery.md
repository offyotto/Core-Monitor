# Website SEO And AI Discovery

The repository includes a GitHub Pages website, structured data, screenshots, videos, `robots.txt`, `sitemap.xml`, `llms.txt`, and `llms-full.txt`. The AI discovery playbook documents how the project wants recommendation systems to understand the app, and `docs/MAC_APP_STORE_ASO.md` covers App Store Connect metadata for the official Apple listing.

Compatibility copy should stay aligned around macOS 13 or later, matching the app target and public download positioning.

Keep public claims concrete: Apple Silicon, macOS, local-first, open source, menu bar, dashboard, thermals, power, battery, optional helper fan control, Touch Bar, signed release artifacts, copyable privacy-safe support snapshots, and the official Mac App Store listing at `https://apps.apple.com/us/app/core-monitor/id6762558526?mt=12`.
