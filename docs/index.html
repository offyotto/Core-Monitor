The instrument panel your Mac never shipped with.

Core-Monitor reads the sensors Apple Silicon already has: CPU load and temperature, power draw, memory, battery, fan speed. It shows them plainly, ten times a second, and when you ask, it hands you the fans. Nothing leaves the Mac.

Your curve, following the live temperature.

macOS keeps the last word. The system's own thermal limits apply regardless of what any app asks for. A curve can run the fans harder or quieter inside those limits, never outside them.

One click gives control back. The switch sits on the same screen as the curve and reads, in full, Hand Cooling Back to macOS.

The helper is optional. Every reading works without it. It exists only to write fan speeds, and it is installed with administrator approval the first time you ask.

The helper watches the connection. Manual targets are supervised while the app stays connected and sends a heartbeat. A lost connection or an expired lease triggers an attempt to return the fans to automatic.

The Touch Bar, put back to work.

On a MacBook Pro with a Touch Bar, Core-Monitor can keep temperature, fan speed, load and network on the strip above the keyboard, where a glance costs nothing. Pick the readings you want there; the system controls stay where they were.

Questions people ask before installing.

Which Macs can run it?

Apple Silicon Macs on macOS 13 or later. The sensors and fan interfaces it reads are specific to Apple’s own chips, so Intel Macs are not supported.

Do I need the helper installed?

No. Every reading works without it. It exists only so the app can write fan speeds, and you can hand control back to macOS whenever you like.

Does it phone home?

Core-Monitor has no account, advertising, or analytics, and it does not send monitoring data to the developer. Live Weather is off by default. If you explicitly enable it, the app asks macOS for location access and requests weather from Apple WeatherKit. Turning it off stops Core-Monitor’s weather requests.

Can fan control damage my Mac?

macOS keeps its own thermal limits regardless of what any app requests. Core-Monitor also keeps an obvious way out: one click gives full control back to the system.

What is deliberately left out?

Cloud dashboards, fleet management, and a metric for every corner of the OS. The scope stays heat, power, memory, battery and fans, done properly.

Where do bug reports go?

Open an issue on the GitHub tracker. Release notes and older builds live on the releases page.
