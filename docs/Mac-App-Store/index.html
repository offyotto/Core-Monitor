Mac App Store edition

The same monitor, kept inside Apple's sandbox

This build of Core-Monitor is reviewed and delivered by Apple. It reads and displays; it never writes to hardware. If fan control matters to you, the direct download is the build to use instead.

Open the Apple listing What is in this edition

Exactly what the sandbox allows

App Store rules shape this edition, so the boundaries are written down plainly instead of left implied.

Included

  • Overall CPU activity and per-core load
  • Memory usage and pressure
  • Network throughput and startup disk usage
  • Battery status, thermal state, uptime and load averages
  • Local weather, only after you grant location access
  • SwiftUI dashboard and a menu bar extra

Left out, by design

  • Privileged helper and background services
  • Fan control and any hardware writes
  • Direct sensor access and private frameworks
  • Touch Bar overlays and custom widgets
  • Shell commands and self-updating
01

Installed by Apple

Reviewed, signed and updated through the App Store, inside the standard sandbox that comes with it.

02

WeatherKit, on request

The weather card asks for location only when you turn it on. Decline, and the rest of the app runs unchanged.

03

Nothing collected

No account, no analytics, no advertising code. The privacy policy is a short read on purpose.
